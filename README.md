# AIDM

AIDM 是一款 Windows 下载管理器，支持 HTTP/HTTPS、FTP、BitTorrent、eD2k 等多协议下载，
提供多连接分段、断点续传、队列调度、限速代理与浏览器接管。

## 功能

**下载核心**

- 多连接分段下载，自动探测服务器 Range 支持，不支持时降级单线程
- 断点续传与崩溃恢复：重启后接着下，已完成分片不重下
- 分段校验、失败自动重试，HTTP 429/503 遵循 `Retry-After`
- 全局限速，支持系统代理与手动代理（HTTP / SOCKS5）

**协议支持**

| 协议 | 说明 |
|---|---|
| HTTP / HTTPS | 分段、续传、重定向、自定义请求头、站点凭据与 401 重试 |
| FTP / FTPS | 明文 FTP 与显式 FTPS，支持 `REST` 续传 |
| BitTorrent | 种子与 magnet 链接，逐文件选择，完成后可继续做种 |
| eD2k | 服务器与 Kad 查源、对等传输、入站上传与信用（上传默认关闭） |
| WebDAV | 走 HTTP 下载，支持源站 Digest 认证 |
| 封装链接 | `thunder://`、`qqdl://`、`flashget://`、`fs2you://` |

**任务管理**

- 命名队列：独立默认目录、启停与定时窗口
- 定时下载（cron）、网络失败退避、失败原因分类
- 托盘常驻、完成通知、多语言热切换

**浏览器集成**

- Chrome / Edge 扩展：网页右键接管下载、页面链接与媒体地址收集
- 经原生消息宿主与客户端通信，不修改系统代理与浏览器策略

**应用更新**

- 应用内检查、下载、校验签名并安装更新（MSI / NSIS）

## 安装与使用

### 安装包

从 [Releases](../../releases) 下载安装程序（MSI 或 NSIS）安装后直接运行。

### 从源码构建

需要 Rust ≥ 1.85。

```bash
cargo build --release -p aidm-engine -p aidm-ui
```

产物在 `target/release/`，运行 `aidm-ui.exe` 即可，界面会自动拉起同目录的 `aidm-engine.exe`。

### 基本使用

1. 点击「新建下载」粘贴链接，选择保存目录，立即开始或加入队列
2. 列表支持单击查看属性、右键操作、框选批量开始/暂停/删除
3. 设置页可配置默认目录、连接数、全局限速、代理、定时与更新
4. 关闭窗口默认收进托盘；托盘菜单支持开始全部、暂停全部与完全退出

### 浏览器扩展（可选）

1. 打开 Chrome / Edge 扩展管理页，启用「开发者模式」，选择「加载已解压的扩展程序」指向 `extension/` 目录
2. 在 AIDM 设置 → 浏览器中启用集成，客户端会自动注册原生消息宿主
3. 之后在网页上右键即可使用 AIDM 下载

## 系统要求

- Windows 10 / 11（需要 WebView2 运行时）
- 从源码构建需要 Rust ≥ 1.85

数据目录：`%LOCALAPPDATA%\AIDM`（数据库、日志、引擎端口）
默认保存目录：`%USERPROFILE%\Downloads`
